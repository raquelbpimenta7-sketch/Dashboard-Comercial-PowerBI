## 📌 Sobre o projeto

Este dashboard foi desenvolvido para transformar dados de vendas em informações estratégicas, permitindo acompanhar indicadores comerciais de forma dinâmica.

O projeto apresenta análises de clientes, produtos, faturamento e desempenho comercial utilizando Power BI e DAX.

---

## 🛠 Tecnologias utilizadas

- Power BI
- DAX
- Microsoft Excel
